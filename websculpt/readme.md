# WebSculpt

ブラウザで動作する WebGL ベースの 3D ポリゴンスカルプトツール。単一 HTML ファイルで完結し、インストール不要で使用できます。

---

## 起動方法

`websculpt.html` をブラウザで開くだけです。サーバー不要。

**推奨ブラウザ:** Chrome / Edge（WebGL + OES_element_index_uint 拡張が必要）

---

## ブラシ

| ブラシ | 説明 |
|---|---|
| **Standard** | 法線方向に頂点を押す基本ブラシ |
| **Clay Bump** | Focal を固定して粘土的に盛る |
| **Trim Dynamic** | ヒット平面に投影して面を削ぐ |
| **Move** | 頂点群を 3D 空間で移動 |

### パラメータ

| パラメータ | 説明 | デフォルト |
|---|---|---|
| Size | ブラシ半径 | 0.30 |
| Strength | ブラシ強度 | 0.50 |
| Focal Shift | 影響の集中度（+ で中心集中、− で外縁強調） | 0.00 |

## メッシュ

### 初期形状

| 形状 | 説明 |
|---|---|
| **Flat** | 64×64 グリッドの平面 |
| **Box** | 6 面独立グリッドの立方体 |
| **Sphere** | UV 球（縮退頂点なし） |

### Subdivide

選択中の形状をポリゴン分割して解像度を上げます。

- **Flat:** bilinear リサンプリング（最大 256 分割）
- **Box / Sphere / インポートメッシュ:** 三角形 midpoint 分割（最大 20 万頂点）

---

## Sculptris Pro モード

VIEW セクションの **SCULPTRIS PRO** ボタンで ON/OFF。

ON にするとスカルプト中にブラシ範囲内の大きすぎるポリゴンをリアルタイムで自動分割します。スカルプトした箇所だけ解像度が上がり、触れていない部分は粗いまま維持されます。

- ブラシ半径の 0.6 倍を超えるエッジが対象
- 1 ストロークにつき最大 3 パス分割
- T 字ジャンクション対策済み（分割エッジを共有する全三角形を同時処理）
- 上限 **200,000 頂点**で自動停止
- Smooth ブラシ（Shift）使用中は分割をスキップ

## OPTIONS

| ボタン | 機能 |
|---|---|
| **Symmetry X** | X 軸対称スカルプト |
| **右を左に転写** | +X 側の形状を −X 側にミラーコピー |

## マテリアル・テクスチャ

- **Base Color:** メッシュのベースカラーをカラーピッカーで変更
- **Load Image:** PNG / JPG 画像をテクスチャとして読み込み（UV マッピング適用）
- **Texture:** テクスチャ表示 ON/OFF

## ファイル入出力

### 内部保存（JSON）

| ボタン | 機能 |
|---|---|
| **Save** | 現在のメッシュを JSON ファイルとして保存 |
| **Load** | 保存した JSON を読み込む |

### エクスポート

| 形式 | 備考 |
|---|---|
| **OBJ** | 頂点・法線・UV 付き |
| **GLTF** | Base64 埋め込みバイナリ |
| **FBX** | ASCII 7.4 形式 |

### インポート

`.obj` / `.gltf` / `.glb` を読み込んでそのままスカルプト可能。メッシュは中心・スケール正規化されて配置されます。

---

## UI 表示切り替え

画面右上の **◀ HIDE** ボタンで UI パネルを非表示にして全画面スカルプトモードに切り替えます。**☰ SHOW** で元に戻します。

## 技術情報

| 項目 | 内容 |
|---|---|
| レンダリング | WebGL 1.0 |
| レイキャスト | Möller–Trumbore 法（全三角形交差判定） |
| 法線計算 | 面積加重クロス積 |
| Smooth ブラシ | 隣接リストベース Laplacian 緩和 |
| インデックス型 | OES_element_index_uint 使用時 Uint32（20 万頂点以上対応） |
| 依存関係 | なし（単一 HTML ファイル） |
