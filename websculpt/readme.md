# WebSculpt

ブラウザで動作する WebGL ベースの 3D ポリゴンスカルプトツール。単一 HTML ファイルで完結し、インストール不要。

---

## 起動方法

`websculpt.html` をブラウザで開くだけ。サーバー不要。

**推奨ブラウザ:** Chrome / Edge（WebGL + OES_element_index_uint 拡張が必要）

---

## ブラシ

| ブラシ | 動作 |
|---|---|
| **Standard** | 頂点を法線方向に押す基本ブラシ |
| **Clay Bump** | 粘土的に盛る（Focal 固定） |
| **Trim Dynamic** | ヒット平面に投影して面を削ぐ |
| **Move** | 頂点群を 3D 空間で移動 |

### パラメータ

| パラメータ | 説明 | デフォルト |
|---|---|---|
| Size | ブラシ半径 | 0.10 |
| Strength | ブラシ強度 | 0.50 |
| Focal Shift | 影響の集中度（+ で中心集中 / − で外縁強調） | 0.00 |

Size の数値をダブルクリックすると直接入力できます（0.5 以上も入力可能）。

## メッシュ

### 初期形状

| 形状 | 説明 |
|---|---|
| **Flat** | 64×64 グリッドの平面 |
| **Box** | 6 面独立グリッドの立方体 |
| **Sphere** | UV 球（重複頂点ゼロ・シームなし） |

### Subdivide

ポリゴンを細分割して解像度を上げます。

- **Flat:** bilinear リサンプリング（最大 256 分割）
- **Box / Sphere / インポートメッシュ:** 三角形 midpoint 分割
- UV はシーム補正付きで補間されます

---

## Sculptris Pro

VIEW セクションの **SCULPTRIS PRO** ボタンで ON/OFF。

スカルプト中にブラシ範囲内の大きすぎるポリゴンをリアルタイムで自動分割します。

- ブラシ半径の 0.6 倍を超えるエッジが分割対象
- 1 ストロークにつき最大 3 パス
- Symmetry ON 時は両側を同時に分割
- T 字ジャンクション対策済み（穴が開かない）
- UV はシーム補正付きで補間
- 上限 **200,000 頂点** で自動停止
- Smooth ブラシ（Shift）中はスキップ

---

## Undo

`Ctrl+Z`（Mac: `Cmd+Z`）で 1 ストローク単位で戻ります。最大 **20 ステップ**。Sculptris Pro でトポロジーが変わった状態も含めて完全に復元します。

## OPTIONS

| ボタン | 機能 |
|---|---|
| **Symmetry X** | X 軸対称スカルプト（Sculptris Pro も両側対応） |
| **右を左に転写** | +X 側の形状を −X 側にミラーコピー |
| **Mesh Reset** | 現在の形状を初期状態に戻す |

## マテリアル・テクスチャ

- **Base Color:** ベースカラーをカラーピッカーで変更
- **Load Image:** PNG / JPG をテクスチャとして読み込み
- **Texture:** テクスチャ表示 ON/OFF（PBR マップを含む全スロット制御）

## ファイル入出力

### 内部保存

| ボタン | 機能 |
|---|---|
| Save | メッシュを JSON で保存 |
| Load | 保存した JSON を読み込む |

| 形式 | 備考 |
|---|---|
| **OBJ** | 頂点・法線・UV 付き |

`.obj` / `.gltf` / `.glb` を読み込んでそのままスカルプト可能。PBR テクスチャも自動取り込み。

## 技術情報

| 項目 | 内容 |
|---|---|
| レンダリング | WebGL 1.0 + PBR シェーダー |
| レイキャスト | Möller–Trumbore 法（全三角形交差判定） |
| 法線計算 | 面積加重クロス積 |
| Smooth ブラシ | 隣接リストベース Laplacian 緩和 |
| UV 補間 | シーム検出付き補正（|u1-u0|>0.5 を自動判定） |
| インデックス型 | OES_element_index_uint 使用時 Uint32（20 万頂点以上対応） |
| 依存関係 | なし（単一 HTML ファイル） |
