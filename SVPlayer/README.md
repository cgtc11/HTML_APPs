# Stage Video Player — 使い方ガイド

## 概要

**Stage Video Player** は、ライブステージ・コンサート・イベントなどで使うための動画・画像プレーヤーです。  
HTMLファイル1つをブラウザ（Chrome / Edge 推奨）で開くだけで動作します。インストール不要。

### 主な特徴

- **セグメント構成**で演目の流れを管理（タイトル → 演奏 → MC → … の順に定義）
- **プロジェクター用ウィンドウ**と**本体確認ウィンドウ**を分離して出力
- **動画・画像を混在**して再生可能（順次 / ランダム）
- フォルダ単位でファイルを管理。フォルダを指定するだけで自動認識
- **フェード**（黒へ / 黒から）付きで滑らかに切り替え
- **BLACKOUT**（緊急暗転）機能搭載。暗転中は映像・音声も停止
- **ショートカットキーを自由に設定・保存**可能
- 設定はブラウザに自動保存、JSONファイルへの書き出し / 読み込みも可能

---

## 起動手順

1. `stage-video-player.html` を Chrome または Edge で開く
2. 右上の「**プロジェクター画面を開く**」をクリック → 別ウィンドウが開く
3. プロジェクター用ウィンドウをプロジェクターのモニターへ移動し、クリックして全画面にする
4. ヘッダーの「プロジェクター画面を開く」ボタンが**緑色**になれば接続完了

> **音声について**  
> 音声は本体（コントロール）側のプレビューから出力されます。  
> プロジェクター側は映像のみ・無音です。

## 全機能の説明

---

### セグメント構成（左パネル）

演目の流れを「セグメント」という単位で管理します。  
デフォルトでは タイトル → 演奏１ → MC → 演奏２ … の構成が設定されています。

#### セグメントの各項目

| 項目 | 説明 |
|------|------|
| **番号** | セグメントの順番。再生中はオレンジ色に変わる（クリック直後に即座に変わる） |
| **セグメント名** | クリックして編集可能 |
| **▲ ▼** | セグメントの順番を入れ替える |
| **✕** | セグメントを削除する |
| **順次 / ランダム** | フォルダ内のファイルの再生順。ランダムは全再生後にシャッフルして繰り返す |
| **📂 フォルダを選択** | 動画・画像が入ったフォルダを指定。同一セッション内は前回開いた場所から開く |
| **🖼 〇秒** | 画像の表示秒数。**0 = 手動で次へ進むまで表示し続ける** |
| **🎬 T バッジ** | タイトル画像が検出されたことを示す |
| **▶ PLAY ボタン** | クリックでそのセグメントへ直接ジャンプ。未開始の場合はここからスタートできる |

#### 対応ファイル形式

- **動画**: mp4, webm, mov (H.264), avi, mkv, m4v, ogv, ogg, ts
- **画像**: jpg, jpeg, png, gif, webp, bmp, avif, svg

---

### タイトル画像機能

フォルダ内に **「フォルダ名と同じ名前」の jpg / bmp / png** ファイルがあると、そのセグメントの**最初だけ**タイトル画像として表示されます。

**例：** フォルダ名が `演奏１` の場合 → `演奏１.jpg` または `演奏１.bmp` が対象

- タイトル画像は通常の再生リスト（ランダム・繰り返し）には含まれません
- セグメントに切り替わった瞬間に表示され、**手動で「次へ」または「次のセグメント」を押すまで止まります**
- 検出されたセグメントには **🎬 T** バッジが表示されます

#### タイトル画像表示中の操作

| 操作 | フォルダに他のファイルがある場合 | タイトル画像だけの場合 |
|------|-------------------------------|----------------------|
| **次へ** | フォルダ内の最初のファイルを表示 | 次のセグメントへ進む |
| **次のセグメント** | フォルダ内の最初のファイルを表示 | 次のセグメントへ進む |

---

### フェード機能

ヘッダーの **「フェード 〇秒」** で全切り替え時のフェード秒数を設定します。

- `0` → 即時切り替え（パッと変わる）
- それ以外 → 指定秒数かけて黒にフェードアウトし、次のコンテンツへ切り替えてフェードイン

フェードは以下のすべての操作に適用されます：

- 次へ / 前へ（動画・画像）
- セグメント切り替え（▶ PLAYボタン、SEGボタン含む）
- 再生 / 一時停止ボタン
- BLACKOUT の入り / 戻り

**プロジェクターと本体プレビューのフェードは同時に開始**されます。

---

### ボタンの「次に押すべき」表示

操作の流れを視覚的にガイドします：

| 状態 | ▶/⏸ ボタン | SEG ⏭⏭ ボタン |
|------|-----------|--------------|
| 待機中・一時停止中 | **オレンジ**（▶ を押せ） | 通常グレー |
| 再生中 | **オレンジ**（⏸ で止められる） | **ゆっくり点滅オレンジ**（次のSEGへ） |

---

### 再生操作ボタン（右パネル下段）

#### 上段ボタン

| ボタン | デフォルトキー | 動作 |
|--------|------|------|
| **⏮** | `←` | 前の動画・画像へ |
| **↩** | `R` | 現在の動画を最初から再生 |
| **▶ / ⏸** | `Space` | 再生 / 一時停止。フェード付きで切り替わる |
| **⏭** | `→` | 次の動画・画像へ |

#### 下段ボタン（セグメント移動）

| ボタン | デフォルトキー | 動作 |
|--------|------|------|
| **⏮⏮ SEG** | `↑` | 前のセグメントへ |
| **SEG ⏭⏭** | `↓` | 次のセグメントへ（タイトル画像中は内容表示） |

スタート前はグレーアウトして無効。スタート後に有効になります。

---

### ショートカットキー設定

ヘッダーの **「⌨ SC設定」** ボタンをクリックするとショートカット設定ダイアログが開きます。

#### 設定方法

1. **「⌨ SC設定」** をクリック
2. 変更したいアクションのキー欄をクリック（オレンジ色になる）
3. 割り当てたいキーを押す
4. **「保存」** をクリックして確定

| 操作 | 説明 |
|------|------|
| キー欄クリック | そのアクションのキー待ち状態（オレンジ表示） |
| 任意のキーを押す | そのキーが割り当てられる |
| `Escape` | そのアクションの変更をキャンセル |
| 「デフォルトに戻す」 | 初期設定に戻す（保存するまで確定しない） |
| 「保存」 | 設定を確定してIndexedDB・JSONに反映 |
| モーダル外クリックまたは✕ | キャンセルして閉じる |

#### デフォルトのショートカット

| キー | 動作 |
|------|------|
| `Space` | 再生 / 一時停止 |
| `→` | 次の動画・画像 |
| `←` | 前の動画・画像 |
| `R` | 現在のコンテンツを最初から |
| `↓` | 次のセグメント |
| `↑` | 前のセグメント |
| `H` | プレビュー表示 / 非表示 |
| `B` | BLACKOUT 切替 |

---

### プレビュー（本体確認用映像）

右パネル上部に本体確認用のプレビュー映像が表示されます。

- **音声はプレビューから出力**されます（プロジェクター側は無音）
- 動画再生中はプレビュー下に**タイムライン**が表示され、ドラッグでシークできます（プロジェクター側も同期）
- **「プレビュー 非表示」ボタン**でプレビューを消して処理負荷を下げられます
- 再表示する時はプロジェクターと同じ位置から自動的に再開します

---

### BLACKOUT（緊急暗転）

**⬛ BLACK OUT** ボタン（またはデフォルトキー `B`）で緊急暗転します。

1. 押すとフェード秒数で黒画面（または設定した画像）にフェードイン
2. フェードイン完了後に**映像・音声を自動停止**
3. 「**◀ 復帰（BlackOUT中）**」をもう一度押すと映像・音声を再開してからフェードアウトして戻る
4. 画像タイマー（imgDur）が設定されている場合、BLACKOUT中の経過時間を差し引いた残り時間から再開

#### BLACKOUT画像の設定

| ボタン | 動作 |
|--------|------|
| **🖼** | 画像ファイルを選択（黒一色の代わりに表示） |
| **✕** | 選択した画像をクリアして黒に戻す |

---

### プロジェクター画面

「**プロジェクター画面を開く**」で別ウィンドウが開きます。

- 開いたらウィンドウをクリックして**全画面表示**にしてください
- 接続中はヘッダーのボタンが**緑色**に変わります
- ウィンドウを閉じると自動的に「未接続」に戻ります（1秒ごとに監視）
- コンテンツ再生のたびにプロジェクターウィンドウが前面に表示されます
- **プロジェクター側は映像のみ・無音**です

---

### 設定の保存・読み込み

#### 自動保存（IndexedDB）

以下の設定はブラウザを閉じても自動的に保存・復元されます：

- セグメント名・再生モード・画像表示秒数
- フェード秒数
- **ショートカットキー設定**

> **注意**: IndexedDBはブラウザのデータに紐付いています。「閲覧データを削除」するとIndexedDBも消えます。HTMLファイルを別の場所に移動した場合は引き継がれません。

#### JSONファイルへの書き出し（📤 設定保存）

以下の設定をすべて `.json` ファイルとして保存できます：

- セグメント名・再生モード・画像表示秒数
- フェード秒数
- **ショートカットキー設定**

`stage-video-player.html` と同じフォルダに保存しておくと管理しやすいです。

#### JSONファイルからの読み込み（📥 設定読込）

保存した `.json` ファイルを読み込みます。  
セグメント構成・フェード秒数・ショートカット設定がすべて復元されます。  
（フォルダのパス指定は再度必要です）

---

### 保存設定の保管場所

| 種別 | 場所 | 特徴 |
|------|------|------|
| **IndexedDB** | ブラウザ内部 | 自動保存・自動復元。ブラウザデータ削除で消える |
| **JSONファイル** | 任意の場所 | 手動書き出し。別PCへの移行や共有が可能 |

> ブラウザのIndexedDBは `F12` → Application → IndexedDB → `StageVP` → `cfg` で確認できます。

## 注意事項

- **対応ブラウザ**: Chrome / Edge（最新版）のみ。Safari・Firefox は File System Access API 非対応のため動作しません
- **フォルダのアクセス権**: ブラウザがフォルダへのアクセスを求めるダイアログが出ます。「許可」を選択してください
- **MOV形式**: H.264コーデックのみ対応。ProResなどは再生できません
- **タイトル画像の命名**: ファイル名（拡張子なし）がフォルダ名と完全一致（大文字小文字不問）する必要があります。対応拡張子は `.jpg` `.jpeg` `.bmp` `.png` のみ

## よくある質問

**Q. プロジェクターに映像が出ない**  
A. プロジェクターウィンドウを開いたらクリックして全画面にしてください。ヘッダーのボタンが緑色になっていれば接続済みです。

**Q. 音が出ない**  
A. 音は本体（コントロール）側のプレビューから出力されます。プロジェクター側は無音です。

**Q. フォルダを選択してもファイルが認識されない**  
A. 対応していない拡張子のファイルは無視されます。サブフォルダ内のファイルは読み込まれません。フォルダ直下にファイルを置いてください。

**Q. 設定が消えた**  
A. ブラウザのデータを削除するとIndexedDBも消えます。定期的に「📤 設定保存」でJSONファイルにバックアップしておくことをお勧めします。

**Q. ショートカットキーを元に戻したい**  
A. 「⌨ SC設定」→「デフォルトに戻す」→「保存」で初期設定に戻ります。

**Q. 設定を別のPCに移したい**  
A. 「📤 設定保存」でJSONファイルに書き出し、移行先で「📥 設定読込」で読み込んでください。フォルダのパス指定は再度必要です。
