ドキュメント ⇔ Excel 相互一括変換ツール

ファイルを該当するエリアに落とすだけで、自動変換・保存されます。

① Markdown / TXT を HTML に変換する

ここに【 .md 】または【 .txt 】ファイルをドロップしてください

② HTML を Markdown に変換する

ここに【 .html 】ファイルをドロップしてください（.mdに変換されます）

③ テキストや表データを Excel に変換する

ここに【 .md 】/【 .html 】/【 .txt 】をドロップ（.xlsxに変換されます）

④ Excel を Markdown / HTML の表に変換する

ここに【 .xlsx 】ファイルをドロップ（.mdと.htmlの表データが出力されます）
