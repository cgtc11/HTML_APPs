# LOOP STUDIO

ブラウザで動くシングルファイルDAW（Digital Audio Workstation）。  
インストール不要。`loop_studio.html` をブラウザで開くだけで使えます。

---

## 動作環境

| ブラウザ | 対応状況 |
|---|---|
| Chrome / Edge | ✅ 推奨 |
| Firefox | ✅ 動作確認済み |
| Safari | ⚠️ Web MIDI API 非対応（MIDIキーボード接続不可） |

外部ライブラリ・サーバー不要。MP3書き出し時のみ lamejs を cdnjs から自動取得します。

---

## 起動方法

```
loop_studio.html をダブルクリック → ブラウザで開く
```

## ショートカットキー（デフォルト）

| キー | 機能 |
|---|---|
| `7` | REC ARM（録音準備） |
| `8` | PLAY（再生） |
| `9` | STOP（停止・REC解除） |
| `1` | オクターブ − |
| `2` | オクターブ + |
| `Space` | 再生 / 停止トグル |
| `Ctrl+Z` | Undo（最大20ステップ） |
| `Ctrl+C` | 選択クリップをコピー |
| `Ctrl+V` | 選択トラックにペースト |
| `Escape` | クリップ選択解除 |

**⚙ SETTINGS** ボタンで全ショートカットをカスタマイズできます。

### ピアノ鍵盤（PC キーボード）

```
白鍵:  A S D F G H J K L ;  '
       （+ T Y で F#, G# も演奏可）
黒鍵:  W E U
```

## トラック

### SYNTH トラック
- MIDIノートをソフトウェア音源で再生
- **+ MIDI** ボタンで `.mid` / `.midi` ファイルを読み込み
- **+ NEW CLIP** で新規録音クリップを作成
- ダブルクリック or **✏ EDIT** でピアノロールエディタを開く

### AUDIO トラック
- **+ MP3/WAV** ボタンで音声ファイルを読み込み
- 対応形式: `.mp3` / `.wav` / `.ogg` / `.flac` / `.m4a`

### 共通操作
| 操作 | 内容 |
|---|---|
| クリップをクリック | 選択（上部パネルに詳細表示） |
| クリップをドラッグ | 時間軸上で移動 |
| クリップ右端をドラッグ / Shift+ドラッグ | Trim OUT を変更 |
| クリップをダブルクリック | MIDIエディタを開く（SYNTHのみ） |
| ルーラーをクリック / ドラッグ | 再生ヘッドをシーク |
| `[M]` ボタン | トラックミュート |
| `[R]` ボタン | 録音 ARM（SYNTHトラックのみ） |
| `[↑][↓]` ボタン | トラック順序を入れ替え |
| `[DEL]` ボタン | トラック削除 |
| ボリュームスライダー | トラック音量 |

## クリップ選択パネル（上部）

クリップ選択時に表示されます。

| 項目 | 内容 |
|---|---|
| TRIM IN | 再生開始位置（秒） |
| TRIM OUT | 再生終了位置（秒、空欄=最後まで） |
| LOOP | ループ回数（0=無限）※AUDIOのみ |
| COLOR | クリップの色 |
| ⧉ COPY | クリップをコピー |
| × DELETE | クリップを削除 |

## MIDIピアノロールエディタ

クリップをダブルクリック or **✏ EDIT** で開きます。  
**録音中・ARM中は開けません。**

### ツール

| ツール | 操作 |
|---|---|
| ✦ SELECT | ノートをクリック選択・ドラッグ移動 |
| ✏ DRAW | クリックでノート追加・右端ドラッグで長さ変更 |
| ⊘ ERASE | クリックでノート削除 |

### ノート操作

| 操作 | 内容 |
|---|---|
| ノートをドラッグ | 音程・時間を移動（低音が上、高音が下） |
| ノート右端をドラッグ / Shift+ドラッグ | 長さを変更 |
| 右クリック | コンテキストメニュー（ミュート / Solo / 削除） |
| `M` キー | 選択ノートのミュート切替 |
| `Delete` / `Backspace` | 選択ノートを削除 |
| **M MUTE SEL** | 選択ノートをミュート |
| **☆ SOLO SEL** | 選択ノートのみ鳴らす（他をミュート） |
| **UNMUTE ALL** | 全ノートのミュートを解除 |
| **× DEL SEL** | 選択ノートを削除 |

### ベロシティレーン（VEL）

エディタ下部の棒グラフ。棒をドラッグして音量（velocity）を変更できます。  
複数ノートを選択した状態でドラッグすると一括変更。

### スクロール・ズーム（ピアノロール内）

| 操作 | 内容 |
|---|---|
| マウスホイール | 縦スクロール（音域） |
| Shift + ホイール | 横スクロール（時間） |
| ズームスライダー | 表示倍率変更 |
| ルーラークリック / ドラッグ | 再生ヘッドをシーク |

## 音色（SYNTH トラック）

| 音色 | 特徴 |
|---|---|
| SYNTH | 矩形波+ノコギリ波のデフォルト音色 |
| LEAD | ノコギリ波+ビブラート |
| BASS | サイン波・1オクターブ低い |
| PAD | 三角波・遅いアタック |
| PLUCK | 減衰するアタック音 |
| DRUM | ノート番号で音色マッピング（C=キック、D=スネア、F#=クローズHH、A#=オープンHH） |

## 録音

1. **SYNTH トラック**を選択（クリック）
2. `7` または **REC** ボタンでARMする
3. `8` または **PLAY** ボタンで録音開始
4. ピアノ鍵盤を演奏
5. `9` または **STOP** で停止 → 録音自動終了・ARM解除

### ループ録音
**⟳ LOOP** をONにして FROM / TO 秒を設定すると、  
ループ範囲内で繰り返し録音（オーバーダブ）できます。

### 追記録音 vs 新規録音
- **ARM時にクリップが0個** → 新規クリップを自動作成
- **ARM時にクリップが存在する** → 最後のクリップに追記
- 新しいクリップに録音したい場合は **+ NEW CLIP** を先に押す

## メトロノーム

**♩ METRO** ボタンでBPMに連動したクリック音をON/OFF。  
BPMはスライダーと数値入力フィールドの両方で変更できます。

## MIDIキーボード

Web MIDI APIに対応したブラウザ（Chrome / Edge）では、  
MIDIキーボードを接続すると自動認識されます。  
画面右上の **MIDI: Nデバイス** バッジで接続状態を確認できます。

---

## ループ設定

| 項目 | 内容 |
|---|---|
| ⟳ LOOP | ループON/OFF |
| FROM | ループ開始位置（秒） |
| TO | ループ終了位置（秒） |

再生ヘッドがFROM〜TOの範囲内にある場合、PLAYを押すとその位置から再生開始。  
範囲外の場合はFROMから再生されます。

## プロジェクトの保存・読み込み

| ボタン | 内容 |
|---|---|
| 💾 SAVE | プロジェクトを `.lsproject`（JSON）として保存 |
| 📂 LOAD | `.lsproject` を読み込んで復元 |

> **注意:** オーディオクリップ（MP3/WAV）のバッファはJSONに保存できません。  
> ロード後、音声ファイルを再インポートしてください。MIDIデータは完全に保存されます。

---

## 書き出し（EXPORT）

**⬇ EXPORT** ボタンで書き出しモーダルを開きます。

| 形式 | 内容 |
|---|---|
| 🎵 WAV | 全トラックをミックスダウンして非圧縮WAVで保存 |
| 🎵 MP3 | 同上、192kbps MP3で保存（初回のみライブラリ読込あり） |
| 🎹 MIDI | 全SYNTHトラックのノートデータをMIDIファイルで保存 |

WAV/MP3は曲が長いほど処理時間がかかります。進捗バーで状態を確認できます。

---

## Undo

`Ctrl+Z` で最大20ステップ戻せます。  
ピアノロールエディタ内でも `Ctrl+Z` が使えます。
