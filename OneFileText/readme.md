# OneFileText HTML版

複数のテキストファイルを1つにまとめるシンプルなツール。ブラウザで使える HTML/JavaScript 版です。

## 🎯 何ができるか

- 複数のテキストファイルをドラッグ＆ドロップで追加
- ファイル選択でも追加可能
- 各ファイル名と 50 文字の区切り線を挿入して結合
- 結合結果を `combined.txt` としてダウンロード

## 💡 使用例

### 結合前
**A.txt**
```
aaaaaaaaaaa
aaaaaa
aaaaaaaaaaa
```

**B.txt**
```
bbbbbbbbb
bbbb
bbbbbbbb
```

### 結合後（combined.txt）
```
A.txt
--------------------------------------------------
aaaaaaaaaaa
aaaaaa
aaaaaaaaaaa
--------------------------------------------------
B.txt
--------------------------------------------------
bbbbbbbbb
bbbb
bbbbbbbb
--------------------------------------------------
```

## 📝 対応ファイル形式

- `.txt`（テキストファイル）
- `.config`（設定ファイル）
- `.csproj`（プロジェクトファイル）
- `.md`（マークダウン）
- その他テキストベースのあらゆる拡張子

## 🚀 使い方

### 1. ファイルを開く
`OneFileText.html` をブラウザで開く（Chrome、Firefox、Safari など）

### 2. ファイルを追加
以下の方法でファイルを追加：
- ドラッグ＆ドロップで追加
- 「ファイルを選択」ボタンで複数選択

### 3. 結合してダウンロード
「📥 ダウンロード」ボタンをクリック

### 4. オプション
- 「✕ クリア」でリストをリセット

## 🎨 特徴

- シンプルで分かりやすい UI
- ローカルで動作（データがサーバーに送信されない）
- インストール不要
- 拡張子の制限なし

## 📂 ファイル構成

```
OneFileText/
├── OneFileText.sln              # 元の C# プロジェクト（Visual Studio）
├── OneFileText/                 # C# ソースコード
├── OneFileText.html             # ブラウザ版（このファイル）
├── HTML_README.md               # このファイル
└── README.md                    # 元のプロジェクト説明
```

## 🔧 オリジナル版

- **言語**: C#（.NET Framework 4.7.2）
- **UI**: Windows Forms
- **用途**: ChatGPT に長文を提供する際に原文を保持するため

## 📌 注意事項

- ブラウザの `File API` を使用するため、最新ブラウザの使用を推奨
- ファイルはローカルで処理され、サーバーに送信されません
- 大きなファイルの場合、ブラウザが若干重くなる可能性があります

## 💻 ブラウザ対応

- Chrome 13+
- Firefox 3.6+
- Safari 5.1+
- Edge 12+
