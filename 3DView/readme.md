# 3DView

ブラウザで動くローカル3Dモデルビューア。インストール不要。  
`3DView.html` をブラウザで開くだけで使えます。ネット接続が必要です（ライブラリをCDNから読み込みます）。

---

## 対応フォーマット

| フォーマット | 内容 |
|------------|------|
| **OBJ** | MTLファイルを同時ドロップするとマテリアル適用 |
| **FBX** | スキニング・ボーン・アニメーション対応 |
| **GLTF / GLB** | フルPBR・アニメーション・モーフターゲット対応 |
| **VRM 0.x / 1.x** | @pixiv/three-vrm、座標系自動補正、SpringBone内蔵物理 |
| **HDR / EXR** | 環境マップとして読み込み可能 |

> OBJ+MTLは複数ファイルを同時ドロップ。外部テクスチャ参照はブラウザのセキュリティ上読み込めません。

---

## モデルを開く

- ウィンドウにファイルをドラッグ＆ドロップ
- または起動画面をクリックしてファイル選択
- 読み込み後は左パネルの「別のファイルを開く」で切り替え

---

## カメラ操作

| 操作 | 動作 |
|------|------|
| 左ドラッグ | カメラ回転 |
| 右ドラッグ | カメラパン |
| スクロール | ズーム |

---

## ツールバー

画面下中央に2段で表示されます。

### 1段目

| ボタン | 動作 |
|--------|------|
| **GRID** | グリッド表示切替 |
| **WIRE** | ワイヤーフレーム切替 |
| **XRAY** | XRAY / BONE / OFF を順番に切替 |
| **LIGHT** | ライティングパネル開閉 |
| **PHYSICS** | 物理演算ON/OFF（青=有効） |
| **ANIM** | アニメーションON/OFF（青=再生中） |
| **RESET CAM** | カメラ位置をリセット |
| **BG** | 背景色を順番に切替（5種類） |

### 2段目

| コントロール | 動作 |
|------------|------|
| **ROT:CAM** | スリープ時にカメラがモデルを周回（デフォルト） |
| **ROT:OBJ** | スリープ時にモデル自体が回転 |
| **IDLE** | 操作なしでスリープに入るまでの時間（3〜60秒） |
| **ROT SPD** | スリープ時の自動回転速度 |

---

## XRAY / BONEモード

`XRAY` ボタンをクリックするたびに3段階を循環します。

| 状態 | 見た目 |
|------|--------|
| **OFF** | 通常表示 |
| **XRAY ON** | メッシュ半透明 + 骨ラインを前面表示 |
| **BONE** | メッシュ非表示、骨ラインのみ |

---

## ROT:OBJ モード

モデル自体が回転します。スキニング揺れ物の確認に使います。

| 操作 | 動作 |
|------|------|
| 左ドラッグ | モデル回転 |
| 右ドラッグ | モデルを上下左右に移動 |
| スクロール | ズーム（カメラ） |
| スリープ | 自動でモデルが回転し続ける |

---

## ライティングパネル（LIGHT）

| セクション | 設定項目 |
|-----------|---------|
| Key Light | 強度 / 水平角（Azimuth）/ 仰角（Elevation） |
| Fill Light | 強度 / 水平角 / 仰角 |
| Rim Light | 強度 / 水平角 / 仰角 |
| Ambient | 強度 |
| Renderer | Exposure（トーンマッピング露出） |
| HDR Environment | 後述 |

HDR使用中かつ「HDR時ライトをOFF」がONの場合、Key / Fill / Rim / Ambientはグレーアウトされます。

---

## HDR Environment

`.hdr` または `.exr` を環境マップとして使用できます。

| コントロール | 動作 |
|------------|------|
| ドロップゾーン | クリックまたはファイルをドロップして読み込み |
| **ENV INT** | 環境光の強度 |
| **ROTATE** | 環境マップを水平方向に回転（0〜360°） |
| **HDR時ライトをOFF** | 手動ライトを自動無効化 |
| **HDRを背景に表示** | HDR画像をシーン背景に使用 |
| **✕ボタン** | HDRを解除してデフォルト環境に戻す |

シーン上にファイルをドラッグ＆ドロップでも読み込めます。

## Physicsパネル（PHYSICS）

### VRM

VRM SpringBoneが内蔵されており、ROT:OBJモードで自動的に髪・スカートが揺れます。設定不要。

### FBX / GLTF

ボーン名または構造から揺れ物チェーンを自動検出します。

検出対象キーワード（ボーン名に含まれる場合）:  
`hair, skirt, cloth, tail, ribbon, spring, bone, joint` など

| スライダー | 意味 |
|-----------|------|
| **STIFF** | バネの硬さ。高いほど素早く戻る |
| **DAMP** | 減衰。高いほど揺れが止まりやすい |
| **DRIVE** | 慣性の強さ。高いほど大きく揺れる |
| **ROOT DRV** | 根本の反応割合（0=先端のみ、1=根本も同じ強さ） |
| **ROOT°** | 根本の最大角度 |
| **TIP×** | 先端への倍率 |
| **GRAVITY** | 重力の影響（先端が垂れる量） |

> 揺れ物が動くにはメッシュにウェイトが必要です。BONEモードで骨が動いているか確認できます。

---

## アニメーションパネル

アニメーション付きモデルを読み込んだ場合に右パネルに表示されます。

| コントロール | 動作 |
|------------|------|
| クリップ一覧 | クリックで切り替え |
| ▶ / ⏸ | 再生 / 一時停止 |
| ■ | 停止 |
| ↺ | ループON/OFF |
| 速度スライダー | 再生速度（0.1〜3.0x） |

ツールバーの **ANIM**（青=再生中）でアニメーション全体をON/OFFできます。OFFにしてから再度ONにすると最後のクリップから再開します。

---

## スリープ機能

IDLE秒間操作がないと自動スリープします。

- 全UIが1.5秒かけてフェードアウト
- ROT:CAMならカメラが、ROT:OBJならモデルが自動回転
- マウス移動・クリック・キー入力・スクロールで即復帰

## 既知の制限

- OBJ / FBXの外部テクスチャファイルはブラウザのセキュリティ上読み込めません
- FBX/GLTFの揺れ物はウェイトが必要です（VRMは不要）
- 推奨ブラウザ: Chrome / Edge
