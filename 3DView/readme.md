# 3DView

ブラウザで動くローカル3Dモデルビューア。インストール不要、`3DView.html` をブラウザで開くだけで使えます。  
ネット接続が必要です（Three.js / three-vrm をCDNから読み込みます）。

---

## 対応フォーマット

| フォーマット | 内容 |
|------------|------|
| **OBJ** | MTLファイルを同時ドロップするとマテリアル適用 |
| **FBX** | スキニング・ボーン・アニメーション対応 |
| **GLTF / GLB** | フルPBR・アニメーション・モーフターゲット対応 |
| **VRM 0.x / 1.x** | @pixiv/three-vrm v2、座標系自動補正 |
| **HDR / EXR** | 環境マップとして読み込み可能 |

> OBJ+MTLは複数ファイルを同時ドロップ。外部テクスチャ参照はブラウザのセキュリティ上読み込めません。

---

## 使い方

### モデルを開く
- ファイルをウィンドウにドラッグ＆ドロップ
- または起動画面をクリックしてファイル選択
- 読み込み後は左下「別のファイルを開く」で切り替え可能

### カメラ操作
| 操作 | 動作 |
|------|------|
| 左ドラッグ | 回転 |
| 右ドラッグ | パン |
| スクロール | ズーム |

---

## UI説明

### 左パネル（MODEL INFO）
読み込んだモデルの情報を表示します。
- フォーマット / 頂点数 / 三角形数 / メッシュ数 / ボーン数

### 右パネル（LIGHT）
ツールバーの `LIGHT` ボタンで開閉します。

| セクション | 設定項目 |
|-----------|---------|
| Key Light | 強度 / 水平角（Azimuth）/ 仰角（Elevation） |
| Fill Light | 強度 / 水平角 / 仰角 |
| Rim Light | 強度 / 水平角 / 仰角 |
| Ambient | 強度 |
| Renderer | Exposure（トーンマッピング露出） |
| HDR Environment | 後述 |

**HDR使用中かつ「HDR時ライトをOFF」がONの場合、Key / Fill / Rim / Ambientはグレーアウトされ操作できません。**

### 右パネル（Animation）
アニメーション付きモデル読み込み時のみ表示されます。
- クリップ選択 / 再生・停止・ループ / 再生速度

### ツールバー（画面下中央）

**上段ボタン**

| ボタン | 動作 |
|--------|------|
| GRID | グリッド表示切替 |
| AXES | 座標軸表示切替 |
| WIRE | ワイヤーフレーム切替 |
| LIGHT | ライトパネル開閉 |
| RESET CAM | カメラ位置をリセット |
| BG | 背景色を順番に切替（5種類） |

**下段スライダー**

| スライダー | 内容 |
|-----------|------|
| IDLE | 操作なしでスリープに入るまでの時間（3〜60秒） |
| ROT SPD | スリープ時の自動回転速度（0.05〜3.0） |

## HDR Environment

`.hdr` または `.exr` ファイルを環境マップとして使用できます。

- LIGHTパネルのドロップゾーンにファイルをドロップ、またはクリックして選択
- シーン上にドラッグ＆ドロップでも読み込み可能
- **ROTATE** スライダー（0〜360°）で環境マップを水平回転
- **ENV INT** スライダーで環境光の強度調整
- **「HDR時ライトをOFF」** トグルで手動ライトを自動無効化
- **「HDRを背景に表示」** トグルでHDR画像をシーン背景に使用
- **✕ボタン**でHDRを解除してデフォルト環境に戻す

---

## スリープ機能

モデル読み込み後、一定時間操作がないと自動でスリープに入ります。

- 全UIが1.5秒かけてフェードアウト
- カメラが自動でゆっくり回転
- マウス移動・クリック・キー入力・スクロールで即復帰

待機時間と回転速度はツールバー下段のスライダーで調整できます。

## 既知の制限

- OBJ / FBXの**外部テクスチャファイル**はブラウザのセキュリティ上読み込めません
- GLBに埋め込まれたテクスチャは問題なく読み込めます
- 表示確認はChrome / Edge推奨（Safari未検証）
