# LoPolyEdit — ローポリ 3D メッシュエディタ

ブラウザで動くシングルファイルの3Dポリゴンエディタです。HTMLファイル1つを開くだけで使えます。

---

## 起動方法

`LoPolyEdit.html` をブラウザで開くだけです。インストール不要。

---

## 画面構成

| 領域 | 説明 |
|------|------|
| 上部ツールバー | モード・ツール・表示切替 |
| 3Dビューポート | メッシュの編集エリア |
| 右パネル | 各操作のコントロール |
| 下部ステータスバー | 現在の状態・操作ヒント |
| 右上ViewCube | 視点操作 |

---

## カメラ操作

| 操作 | PC | スマホ |
|------|----|--------|
| 回転 | Alt+左ドラッグ / 中ドラッグ / ViewCubeドラッグ | 1本指（空白部分） |
| パン | 右ドラッグ | 2本指スライド |
| ズーム | スクロール | ピンチイン/アウト |
| ビュースナップ | ViewCubeクリック | ViewCubeタップ |

**ViewCube（右上）** をドラッグで視点回転、クリックで前・後・右・左・上・下にスナップします。

---

## 編集モード

ツールバー左側でモードを切り替えます。

| モード | 対象 |
|--------|------|
| 頂点 | 個々の頂点 |
| エッジ | 辺 |
| 面 | ポリゴン面 |
| OBJ | オブジェクト全体 |

---

## ツール

| ツール | 操作 |
|--------|------|
| □選択 | ドラッグで範囲選択 |
| ↕移動 | 要素をドラッグ移動 / XYZギズモで軸拘束 |
| ↺回転 | 回転ギズモ（X赤・Y緑・Z青） |
| ⇲拡縮 | スケールギズモ |
| ✂カット | 辺または頂点をクリックして切断（2点で自動実行） |
| ＋辺 | 頂点を2つクリックして辺を作成 |
| ⬆押出 | 面をクリック→ドラッグで押し出し / もう一度で解除 |

**共通ショートカット**

- `Ctrl+Z` — Undo
- `Del` / `Backspace` — 選択要素を削除
- `ESC` — 操作キャンセル
- `Ctrl+クリック` — 選択の追加/除去

---

## 右パネル機能

### 選択

- **すべて選択** / **選択解除** / **選択反転**

### 頂点

- **ソフト選択** — ONにすると選択頂点の周囲を半径・強さに応じてなめらかに移動
  - 半径スライダーで影響範囲を調整
  - 強さスライダー(0〜1)で影響の強弱を調整
- **X / Y / Z 座標** — 選択頂点の位置を数値入力
- **頂点+面削除** — 選択頂点とそれに属する面を削除
- **頂点のみ除去** — 面を残して頂点を除去（ディゾルブ）
- **ウェルド** — 選択頂点を重心に統合
- **結合距離** + **近接頂点結合** — 指定距離以内の頂点を自動マージ
- **スムーズ** — 選択頂点（または全頂点）をスムージング
- **面作成モード** — 頂点をCCW順にクリック → Enter/右クリックで面確定 / ESCでキャンセル

### エッジ

- **エッジ作成** — 頂点モードで頂点を2つ選択して辺を追加（頂点が増えない）
- **エッジ分割** — 選択辺の中点に頂点を追加
- **ループカット** — 四角面のループを切断
- **エッジ+面削除** — 辺と隣接面を削除
- **エッジのみ除去** — 辺を消して隣接面をマージ（ディゾルブ）

### 面

- **押し出し（ツール選択）** — ツールバーの⬆押出に切り替え
- **面分割** — 面を中心点で細分化
- **サブディビジョン** — 全面（または選択面）を細分割
- **法線反転** — 面の表裏を反転
- **面削除**

### 法線 / シェーディング

- **スムース** — 選択辺の法線を結合（なめらかなシェーディング）
- **ハード** — 選択辺の法線を分離（くっきりしたエッジ）
- **全スムース / 全ハード** — メッシュ全体に一括適用
- オレンジ色の辺 = ハードエッジ

対象は選択中のモードに応じて変わります（頂点→隣接辺 / エッジ→選択辺 / 面→面の辺 / OBJ→全辺）。

### シンメトリ

- **ON/OFF** — X/Y/Z軸ミラー編集
- **軸選択** — X軸（デフォルト）/ Y軸 / Z軸
- **シンメトリ適用** — 正側を負側にミラーコピー
- デフォルトON（X軸）

### エラー検出

「🔍 エラー検出」で以下を自動チェックし、対象を選択して削除できます。

| エラー種別 | 内容 |
|------------|------|
| 独立頂点 | どの面にも属さない頂点 |
| 重複頂点 | ほぼ同位置にある頂点 |
| 重複面 | 同じ頂点で構成される面が2枚以上 |
| N角形(5+) | 5頂点以上の面 |
| 法線反転 | 内向きになっている面 |

### 設定

| 項目 | 内容 |
|------|------|
| マテリアル | メッシュのカラーを変更 |
| 頂点サイズ | ドットの大きさ（1〜30） |
| エッジ色 | エッジの明るさ（30〜100） |
| BOX分割 | リセット時のボックス分割数 |
| Sym閾値 | シンメトリの境界判定距離 |
| 奥も選択 | OFFにすると表面のみ選択（ボックス選択・クリック両方に効く） |

## OBJファイル

- **OBJ保存** — 現在のメッシュを `.obj` でダウンロード
- **OBJ読込** — `.obj` ファイルを読み込み（f行の頂点インデックスに対応）

---

## スマホモード

「**■POLY**」（左上タイトル）をクリックするとスマホモードに切り替わります。

- 右パネルは **☰** ボタンまたは右クリックで開閉
- もう一度クリックでPCモードに戻る

---

## 動作環境

WebGL対応のモダンブラウザ（Chrome / Firefox / Safari / Edge）。インストール・サーバー不要。

---

## 制限事項

- Undo は最大50ステップ
- エッジ幅の変更はWebGLの仕様により非対応（エッジ色の明度で代替）
- linewidth > 1 はほぼ全ブラウザで無効
