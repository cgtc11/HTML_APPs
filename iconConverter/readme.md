# iconConverter

複数サイズを1つのICOファイルに同梱できる、ブラウザで動くICO変換ツール。

## 使い方

`iconConverter.html` をブラウザで開くだけ。インストール不要。

## 機能

- 画像をドラッグ＆ドロップで読み込み
- 256 / 128 / 64 / 32 / 16 / 8 の各サイズに自動割当
- **縮小のみ**（拡大なし）。画像が小さい場合は対象サイズをスキップ
- 複数回ドロップ時は**既存画像を保持**（新しい画像が小さい場合、既登録の大きいサイズは残る）
- サイズごとにチェックボックスで同梱可否を選択
- PNG-in-ICO形式で出力（32bit ARGB）

## 対応フォーマット

| 形式 | 入力 |
|------|------|
| PNG  | ✅ |
| JPG / JPEG | ✅ |
| BMP  | ✅ |
| GIF  | ✅ |
| TGA（24/32bit、非圧縮・RLE） | ✅ |
| ICO（最大サイズフレームを取得） | ✅ |
| TIFF | ❌（ブラウザ非対応） |

## 出力

PNG-in-ICO 形式（各サイズを32bit PNGとしてICOに埋め込み）。  
256×256 はICO規格に従いディレクトリエントリを `0x00` で記録。

## 動作環境

モダンブラウザ（Chrome / Firefox / Edge / Safari）。  
サーバー不要、ローカルファイルとして動作。
