# PPTXビューア 002 — HTML単体版

**LibreOffice・PowerPoint・Python・サーバーのインストールは不要です。**

1. `PPTXViewer_002.html` を保存します。
2. Windowsの **EdgeまたはChrome** で開きます。HTMLをダブルクリックするか、右クリックの「プログラムから開く」でブラウザーを選んでください。
3. 「PPTXを開く」で資料を選びます。ドラッグ＆ドロップにも対応しています。
4. 「PDFに保存」を押すと、全ページをまとめたPDFがブラウザーのダウンロード先へ保存されます。通常は元の資料と同じ名前の `.pdf` です。

HTMLは1ファイルで動きます。同梱の `サンプル_002.pptx` は動作確認用で、アプリの起動には不要です。資料をインターネットへ送信する機能はありません。元のPPTXも変更しません。

| 操作 | 方法 |
|---|---|
| 前へ・次へ | ボタン／← →／PageUp・PageDown |
| 指定ページへ移動 | 左のサムネイルをクリック／上のページ番号を入力 |
| 先頭・末尾 | Home／End |
| ページ一覧 | 「ページ一覧」で表示切り替え |
| 拡大縮小 | ＋／−（10〜400%） |
| 全体を表示 | 「全体表示」／0キー |
| 全画面 | 「全画面」／Fキー、Escで解除 |
| PDF保存 | 「PDFに保存」 |

## 対応範囲

ブラウザー内でPPTXのZIP/XMLを読み、Canvasへ直接描画します。外部の変換エンジンやCDNライブラリーは使用しません。

- 基本的な日本語・英語の文字、色・フォントサイズ・太字、背景、画像、基本図形、線、グループ、表を表示します。
- マスター／レイアウトからの基本的な位置・文字スタイルの継承に対応します。
- PowerPointと完全に同じ見た目を保証するものではありません。フォント、文字の折り返し、配置、表の結合、特殊な効果・図形などには差が出ます。
- SmartArt、グラフ、数式、WordArt、外部リンク画像などは未対応です。一部は注意文や代替表示を出します。
- 動画・音声・アニメーションは再生しません。非表示スライドも読み込みます。
- PDFは**スライド画像を収めたPDF**です。文字検索・コピーはできません。表示できない要素はPDFにも含まれません。PDF内の画像はJPEG、長辺相当1920pxを目安に描画します。
- パスワード保護されたPPTXは開けません。上限は100MB／300ページです。重い資料では処理に時間がかかります。
- 最新のEdge／Chromeを推奨します。インターネット接続は不要です。

## 検証について

実際の3ページPPTXサンプルを使ったJavaScriptの自動テストで、ZIP展開、スライド数・サイズ、画像参照、文字・図形の描画呼び出し、ページ操作、拡大縮小、PDF構造、破損ファイル拒否を確認しています。

テストにはブラウザーAPIの代替実装を使用しています。この環境のブラウザー確認機能はローカルファイルへのアクセスを拒否するため、Edge／Chromeでの実機操作、Canvasの実際の文字組み、全画面、ダウンロード操作は未検証です。
